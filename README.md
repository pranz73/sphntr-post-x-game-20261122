# Firefly After Dark — one prompt, one tiny browser game

An AI agent built a tiny browser game from a single prompt, then made a short video about it and posted the video natively on X.

**The game:** guide a moth through the night, collect eight fireflies before dawn, and dodge the owl. Keyboard and touch controls, a wingbeat dash, win / lose / restart states. Open `index.html` in a browser to play; `game.mjs` holds the game logic and `main.ts` copies `POST.json` to `/output` as the kit contract requires.

**The post:** https://x.com/el_jordan69/status/2124845846021988720 — a 52-second video (1920×1080) that shows the prompt, the agent building and playing the game, and ends with make.fun's official referral end card carrying the account's own referral code. The video was scripted, captured and rendered with ffmpeg inside the agent's recorded sessions; the rendered file was handed to the account owner to post, as the bounty rules allow.
